We use NE555 to send output to 74LS164. 
The green LED is to prove NE555 is working.
If you adjust the variable resistor, the LED bar will shift faster, same as the Green LED light.
The LED bar lights up one LED at a time at first.
When the button is pressed, the LEDs begin shifting in the opposite pattern: the first lit LED turns off, then turns back on when the LED to its right turns off.
This pattern continues along the LED bar, with one LED off while the previous LED turns on again.
