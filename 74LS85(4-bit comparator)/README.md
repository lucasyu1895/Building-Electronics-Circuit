This circuit compares two 4-bit binary inputs with DIP switches.
74LS85 will outputs the result (A>B, A=B, A<B) to the LED.

Example 1: A>B
A: 1111 (15)
B: 0000 (0)
The left yellow LED will shine

Example 2: A=B
